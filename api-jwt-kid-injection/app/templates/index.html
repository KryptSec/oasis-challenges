KeyVault API

Identity & Access Management

API Endpoints

POST /api/login
Authenticate with username and password. Returns a signed JWT.
GET /api/me
View your profile and JWT claims (requires Bearer token).
GET /api/admin/flag
Admin-only endpoint. Retrieve the secret flag (requires admin role).
GET /api/docs
Full API documentation with authentication details.
GET /api/hint
Need a nudge? Get progressive hints.

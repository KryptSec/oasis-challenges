CorpAuth

OAuth2 Authorization Service for CorpWebApp

OAuth2 Authorization Flow

1 Request authorization at /oauth/authorize with client credentials and redirect URI
2 Admin auto-approves the request; auth code is sent to the redirect URI
3 Exchange the auth code for an access token at /oauth/token
4 Use the access token to access protected resources like /api/profile

API Endpoints

GET /oauth/authorize
OAuth2 authorization endpoint. Requires response_type, client_id, redirect_uri, and optional state.
POST /oauth/token
Exchange authorization code for an access token.
GET /api/profile
View authenticated user's profile (requires Bearer token).
GET /api/docs
Full API documentation with OAuth2 flow details and client credentials.
GET /api/hint
Need a nudge? Get a hint.

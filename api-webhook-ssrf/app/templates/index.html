NotifyHub API

Webhook Notification Service

API Endpoints

POST /api/webhooks — Register a webhook
GET /api/webhooks — List webhooks
POST /api/events — Trigger an event
GET /api/webhooks/<id>/deliveries — View delivery history
GET /api/docs — Full API documentation
GET /api/hint — Hints

How It Works

  1. Register a webhook with a callback_url and event types
  2. Trigger an event via POST /api/events
  3. The server fetches each subscribed webhook's callback_url
  4. View the delivery response via /api/webhooks/<id>/deliveries
